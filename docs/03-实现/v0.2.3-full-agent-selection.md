# v0.2.3 全流程 Agent 选择器 — 实现记录

## 用户需求

在 vela 的所有主流程里，都可以自主选择专业 Agent：
- ✅ 撰写文章 (GenerateDraft)
- ✅ 审稿 (ReviewChapter)
- ✅ 根据审核结果修稿 (RefineFromReview)
- ✅ 自定义修稿 (RefineDraft)
- ✅ 审稿时规避番茄规则
- ✅ 定稿 (Finalize) 出两个版本：番茄小说版 / 微信公众号版
