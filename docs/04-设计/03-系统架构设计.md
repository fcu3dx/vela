## 2. 数据流

```
用户输入 → AgentSelector (选择Agent角色)
         → 输入框 / 快捷菜单 (选择Skill)
         → agent-orchestrator (路由到Agent+Skill)
         → Agent ReAct循环 (agent-engine.ts)
         → Tool调用 (tool-registry.ts)
         → 结果 → UI渲染
```

## 3. Agent 调度器设计

```
agent-orchestrator.ts
  ├── getActiveAgent(): AgentProfile        // 获取当前选择的Agent
  ├── routeIntent(input): {agent, skill}    // 意图→Agent+Skill匹配
  ├── spawnSubAgent(agent, prompt): result  // 子Agent独立ReAct
  └── mergeResults(results[]): summary      // 多Agent结果合并
```

Agent 路由规则：
- 用户显式选择 Agent → 使用该 Agent
- 用户调用 Skill → Skill 前置元数据指定推荐 Agent
- 用户自由对话 → 通用助手 Agent
- `/写大纲` / `/编故事` → story-architect
- `/写正文` / `/续写` → narrative-writer
- `/审查` → consistency-checker
- `/角色` → character-designer
