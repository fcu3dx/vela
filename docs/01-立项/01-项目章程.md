# Vela v0.2.0 项目章程

## 项目名称

**Vela v0.2.0 — AI 小说创作 IDE（二开版本）**

## 项目背景

Vela 是一款由 heider-x 开发的 Electron + React + TypeScript 的 AI 深度驱动小说创作 IDE，当前版本 v0.1.0。它具备：
- 故事架构生成（故事前提 / 角色图谱 / 世界观 / 情节大纲）
- 章节创作流水线（写稿 → 修稿 → 审稿 → 定稿）
- 内置 Agent 引擎（ReAct 循环、Tool Registry、Skill Registry）
- 本地 RAG 知识库（better-sqlite3 + 向量引擎）
- IDE 级四分屏布局（文件树 + 编辑器 + AI 面板 + 底部终端）

但相比 oh-story-claudecode 等专业的网文写作 Agent，Vela v0.1.0 在以下维度存在明显差距：
- 写作流程完整度：缺少扫榜、拆文、去 AI 味、多 Agent 协作等关键能力
- 项目文件管理：没有 oh-story-claudecode 的结构化项目目录（设定/大纲/正文/追踪/对标/拆文库）
- Agent 体系：只有单 Agent，缺少多角色协作（架构师、叙事写手、一致性检查器等）
- Skills 生态：内置 5 个简单 Skill，缺少系统性写作方法论

## 项目目标

以 vela v0.1.0 代码为基础，在 dev 分支上进行二开，集成 oh-story-claudecode 及其他优秀 AI 写作工具的先进功能，保留 vela 的原架构方案，增强以下能力：

1. **全流程写作工作流**：扫榜 → 拆文 → 立项 → 大纲 → 正文 → 精修 → 去 AI 味 → 封面
2. **多 Agent 协作**：至少 5 个专业 Agent（架构师、角色设计师、叙事写手、一致性检查器、故事探索者）
3. **结构化项目文件系统**：对标 oh-story-claudecode 的目录规范
4. **Skills 生态扩展**：内置 12+ 专业 Skill，支持用户自定义 Skill 扩展
5. **对标与拆文**：集成对标书分析、节奏迁移、情绪模块等拆文能力
6. **去 AI 味**：集成本地化去 AI 写作痕迹检测与修复
7. **持续写作追踪**：伏笔追踪、时间线管理、角色状态快照

## 技术约束

- **必须使用 dev 分支**开发，不碰 master/main 分支
- **保留 vela 原有架构方案**：Electron + React + TypeScript + Zustand + better-sqlite3
- **不全新设计应用**：这是二开，不是重写
- **遵循 vela 现有开发规范**（rule.md）：中文注释、文件命名、UI 规范、CSS 变量主题
