# Vela v0.2.0 版本规划

## 版本路线

```
v0.1.0 (原始版本) ──→ v0.2.0 (本次二开) ──→ v0.3.0 (未来迭代) ──→ ... ──→ v1.0.0 (正式版)
```

## v0.2.0 版本目标

基于 vela v0.1.0 代码，集成 oh-story-claudecode 等工具的核心能力。

### 核心交付物

| 模块 | 来源 | 功能 | 优先级 |
|------|------|------|--------|
| **Agent 协作体系** | oh-story-claudecode 7 Agent 模型 | 架构师/角色设计师/叙事写手/一致性检查器/故事探索者 等 5+ Agent | P0 |
| **全流程写作工作流** | oh-story-claudecode Phase 1-5 流程 | 扫榜→拆文→立项→大纲→正文→精修 | P0 |
| **项目文件结构** | oh-story-claudecode 目录规范 | 设定/大纲/正文/追踪/对标/拆文库 | P0 |
| **Skills 生态** | oh-story-claudecode 13 Skill + vela 现有 5 Skill | 内置 12+ Skill + 用户自定义扩展 | P0 |
| **去 AI 味** | story-deslop Skill | 检测并清除 AI 写作痕迹 | P1 |
| **拆文能力** | story-long-analyze + story-short-analyze | 长篇/短篇结构化拆解 | P1 |
| **扫榜能力** | story-long-scan + story-short-scan | 市场趋势分析 + 选题决策 | P1 |
| **多视角审稿** | story-review Skill | 4 Agent 多视角审查 + 平台评分标准 | P1 |
| **对标节奏迁移** | cross-book-recall + outline-structure-theory | 对标书节奏回流、章节定位与张弛 | P2 |
| **伏笔追踪系统** | 追踪/伏笔.md + consistency-checker Agent | 伏笔埋设/回收状态表 | P2 |
| **时间线管理** | 追踪/时间线.md | 故事内时间线追踪 | P2 |
| **角色状态快照** | 追踪/角色状态.md | 角色当前状态跨章节追踪 | P2 |
| **封面生成** | story-cover Skill | AI 封面生成 | P3 |
| **小说导入** | story-import Skill | 已有小说逆向解析为标准项目结构 | P3 |

### 不纳入 v0.2.0 的功能

| 功能 | 原因 |
|------|------|
| CDP 浏览器操控 | vela 是 Electron 应用，浏览器操控需求不同 |
| Claude Code / Codex / OpenCode hooks | vela 不是 CLI Agent，是独立桌面应用 |
| 外部 CLI Agent 适配 | vela 自建 Agent 引擎，不需要适配外部 CLI |

## 版本增量策略

- v0.2.0-beta1：立项完成
- v0.2.0-beta2：需求确认
- v0.2.0-beta3：原型确认
- v0.2.0-beta4：设计完成
- v0.2.0-rc1：编码完成（功能完整，编译通过）
- v0.2.0-rc2：测试通过（零严重 Bug）
- v0.2.0：正式发布

## 关键约束

1. **必须在 dev 分支**上开发，不改动 master/main
2. **保留 vela 所有现有功能**：架构生成、章节流水线、RAG 知识库、MCP、四分屏 UI
3. **不改变 vela 的技术选型**：继续使用 Electron + React + TypeScript + Zustand + better-sqlite3
4. **向前兼容**：现有项目文件和数据格式保持不变，新功能增量添加
5. **遵循 rule.md**的开发规范
