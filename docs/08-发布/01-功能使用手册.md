## 二、v0.2.0 新增功能

### 2.1 多 Agent 协作体系

#### 概念
v0.2.0 引入 13 个专业化 Agent，每个 Agent 是独立的 AI "专家"，有自己的系统提示词、推荐 Skill 和工具权限。你可以在 AI 面板顶部切换 Agent。

#### Agent 选择器
**位置**: AI 面板左上角（原来是 "AGENT" 文字，现在是可点击下拉按钮）

显示形式:
```
[🤖 通用助手 ▾]
```

点击后展开 Agent 列表:
```
选择 Agent 角色
─────────────────
🏗️ 故事架构师        ● 强模型
👤 角色设计师         ● 中模型
✍️ 叙事写手           ● 中模型
🔍 一致性检查器       ● 轻模型
🔎 故事探索者         ● 轻模型
🎯 评论者             ● 强模型
📖 读者模拟器         ● 中模型
🎭 角色模拟器         ● 中模型
💡 脑暴者             ● 任意
📋 大纲师             ● 中模型
🎨 风格创建器         ● 中模型
📜 编年史家           ● 轻模型
```

圆点颜色表示推荐的模型档位: 红=强 黄=中 绿=轻 灰=任意

#### 13 个 Agent 详解

| Agent | 职责 | 适用场景 |
|-------|------|---------|
| 通用助手 | 全能的 AI 创作助手 | 默认、不想手动切换时 |
| 故事架构师 | 故事结构设计、题材定位、大纲、钩子与反转 | "帮我搭新书架构" |
| 角色设计师 | 角色档案、语言风格、动机链 | "帮我设计主角" |
| 叙事写手 | 正文写作、文风保持、日更续写 | "帮我写第5章" |
| 一致性检查器 | 事实冲突扫描、伏笔追踪、设定审计 | "帮我检查有没有矛盾" |
| 故事探索者 | 角色/伏笔/设定快速查询（只读） | "主角目前什么状态？" |
| 评论者 | 深度对抗式批评，只挑问题 | "狠狠批我的稿子" |
| 读者模拟器 | 以读者视角模拟阅读体验 | "读者看到这章什么感觉？" |
| 角色模拟器 | 以角色身份对话 | "我想和主角聊聊" |
| 脑暴者 | 创意发散，生成多样选项 | "帮我脑暴几个情节点子" |
| 大纲师 | 方向序列化为可执行大纲 | "把方向变成具体细纲" |
| 风格创建器 | 分析文风，生成风格参考 | "分析我这篇的风格" |
| 编年史家 | 提取事实更新知识库 | "把新章节更新到知识库" |

#### 智能路由

v0.2.0 支持 4 层自动路由:

- **显式 `/skill` 调用**: 输入 `/novel-draft` → 自动激活叙事写手
- **自然语言触发词**: 输入 "帮我写大纲" → 自动激活故事架构师
- **Skill whenToUse 匹配**: 输入意图被 Skill 注册的 whenToUse 覆盖 → 激活对应 Agent
- **默认 fallback**: 未匹配 → 通用助手

### 2.2 Skills 生态扩展

#### 概念
v0.2.0 内置 Skill 从 5 个扩展到 28 个。每个 Skill 是一个知识包（系统提示词片段），可通过 `/skill-name` 命令在对话中调用。

#### 调用方式
- 在 AI 对话中输入 `/` 触发命令菜单
- 直接输入 `/skill-name`（如 `/novel-outline`）
- Agent 可自动推荐和调用关联 Skill

#### P0 核心 Skill（11 个新增）

| Skill | 命令 | 功能 |
|-------|------|------|
| 大纲搭建 | `/novel-outline` | 选题→核心设定→大纲的全流程，含五检和投放建议 |
| 长篇写作 | `/novel-draft` | 按细纲写正文，文风保持，日更续写 |
| 长篇拆文 | `/novel-analyze` | 拆解长篇小说五维评分，可借鉴套路提取 |
| 去 AI 味 | `/deai-filter` | 7 Gate 检测 + 三遍修复法，最小改动去 AI 痕迹 |
| 多视角审稿 | `/multi-review` | 结构/角色/文字/设定四维度审查 |
| 角色对话模拟 | `/character-sim` | 以角色身份对话，发现角色声音 |
| 读者模拟 | `/reader-sim` | 以指定读者画像视角模拟首次阅读体验 |
| 风格创建 | `/style-creator` | 分析散文样本，生成可复用风格参考文件 |
| 写作模式 | `/writing-modes` | 4 种模式切换: 探索/日常/打磨/突破 |
| 写作原则 | `/writing-principles` | 核心写作原则: 展示不要说、晚进早出、场景为王 |
| 故事记忆 | `/story-memory` | 用结构化标准维护不断生长的知识库 |

| Skill | 命令 | 功能 |

## 三、典型工作流

### 3.1 新书搭建

1. 创建新项目
2. AI 面板选 "故事架构师"（或用 "帮我搭新书架构" 自动路由）
3. 输入 `/novel-outline` 启动大纲搭建流程
4. 架构师引导确认选题 → 核心设定 → 卷级大纲 → 第1-10章细纲
5. 选 "叙事写手"，输入 `/novel-draft` 开始写正文

### 3.2 日更续写

1. 选 "叙事写手"
2. 输入 `/novel-draft` → AI 自动加载追踪上下文 + 角色状态 + 当前细纲
3. 写正文
4. 写完后选 "编年史家"，输入 `/story-memory` 更新知识库

### 3.3 审稿润色

1. 选 "评论者" → 输入 `帮我审稿` → 获得问题清单
2. 选 "叙事写手" → 输入 `/deai-filter` → 去 AI 味
3. 选 "一致性检查器" → 输入 `/continuity-check` → 检查矛盾

### 3.4 角色开发

1. 选 "角色设计师" → 设计角色档案
2. 选 "角色模拟器" → 输入 `/character-sim` → 和角色对话
3. 选 "读者模拟器" → 输入 `/reader-sim` → 看读者对角色反应

## 五、常见问题

### Q: 如何回到默认模式？
A: 在 Agent 选择器下拉中选 "通用助手"。

### Q: Skill 太多记不住怎么办？
A: 在 AI 对话中输入 `/` 即可看到全部 Skill 列表，按分类排列。

### Q: Agent 会自动切换吗？
A: 会。输入包含触发词（如 "帮我写大纲"）时自动激活对应 Agent。

### Q: 切换 Agent 会丢失对话吗？
A: 不会。切换 Agent 只改变系统提示词，对话历史和会话继续保留。
