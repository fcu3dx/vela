## 1. 产品概述

**Vela v0.2.0** 是在原 vela AI 小说创作 IDE 基础上，系统性集成 oh-story-claudecode、creative-writing-skills、awesome-claude-skills 等工具的核心方法论和功能，升级为一款**专业级 AI 写作工作站**。

## 2. 功能详细规格

### 2.1 Agent 协作体系（P0）

#### 2.1.1 Agent 调度器

```
agent-orchestrator.ts
  ├── Agent 注册 — 每个 Agent = system prompt + 工具白名单 + 推荐模型
  ├── Agent 调用 — spawn 子 ReAct 循环，独立上下文
  ├── Agent 结果合并 — 多 Agent 输出汇总
  └── Agent 路由 — 根据用户意图自动选择 Agent
```

#### 2.1.2 Agent 列表

| # | Agent | 模型档位 | 工具白名单 |
|---|-------|---------|-----------|
| 1 | story-architect | 强推理 | read_*, write_file, search_knowledge |
| 2 | character-designer | 中等 | read_characters, write_file, search_knowledge |
| 3 | narrative-writer | 中等 | read_*, write_file, start_workflow |
| 4 | consistency-checker | 轻量 | read_*（全部只读） |
| 5 | story-explorer | 轻量 | read_*（全部只读） |
| 6 | critic | 强推理 | read_drafts, read_architecture |
| 7 | editor | 中等 | read_*（全部只读） |
| 8 | reader-sim | 中等 | read_drafts |
| 9 | character-sim | 中等 | read_characters |
| 10 | brainstormer | 任意 | read_project_state |
| 11 | outliner | 中等 | read_architecture, write_file |
| 12 | style-creator | 中等 | read_drafts, write_file |
| 13 | chronicler | 轻量 | read_drafts, write_file |

#### 2.1.3 用户交互

- AI 面板顶部新增「Agent 选择器」下拉菜单，显示 13 个 Agent
- 默认 Agent 为「通用助手」（当前 vela 行为）
- 用户可手动切换，系统根据用户意图自动匹配

### 2.2 Skills 生态（P0）

#### 2.2.1 Skill 列表（28 个）

基础层（3 个）：
- `project-init`：项目初始化 + 目录结构 + Agent 注册
- `writing-toolbox`：意图路由 + Skill 自动分发
- `style-creator`：从散文样本分析并创建风格文件

核心层（8 个）：
- `novel-outline`：选题确认→核心设定→大纲搭建（卷纲+细纲）
- `novel-draft`：正文生成+上下文字段追踪+日更续写
- `novel-analyze`：长篇拆文（黄金三章/爽点/节奏/情绪模块）
- `short-write`：短篇写作（情绪设计/反转构思/精修出稿）
- `short-analyze`：短篇拆文（故事核/反转/情感线）
- `deai-filter`：去 AI 味检测（7 Gate）+ 三遍修复
- `multi-review`：多视角对抗式审稿 + 平台评分标准
- `character-sim`：与角色对话模拟声音+关系测试

进阶层（8 个）：
- `market-scan`：市场扫榜（平台趋势+选题决策）
- `novel-import`：已有小说逆向解析为标准项目结构
- `cover-gen`：AI 封面生成
- `story-memory`：事实提取+知识库更新+问题追踪
- `writing-modes`：写作模式切换（新稿/修订/桥接/替代/润色）
- `writing-principles`：写作原则（读者奖励通道+AI失败模式）
- `llm-discipline`：LLM 默认词/句式检测替换

辅助层（5 个原有 + 4 个新增）：
- `review-chapter`：章节级质量审阅（保留）
- `brainstorm`：创意脑暴（保留）
- `character-analysis`：角色深度分析（保留）
- `continuity-check`：连续性一致性检查（保留+增强）
- `writing-coach`：写作教练（保留）
- `research-assist`：多源研究+引用+大纲生成（新增）
- `brand-voice`：品牌声音分析（新增）
- `headline-gen`：标题A/B变体+评分（新增）
- `doc-export`：文档导出 DOCX/PPTX/PDF（新增）

#### 2.2.2 Skill 面板 UI

- 侧边栏新增「Skills」Tab
- 按分类折叠展示（项目初始化/市场调研/故事架构/正文写作/精修润色/角色与读者/辅助工具）
- 每个 Skill 显示名称+描述+触发短语
- 点击 Skill 即注入到 AI 面板开始对话
- 用户自定义 Skill 放在 `.vela/skills/` 目录下自动加载

### 2.3 项目文件结构升级（P0）

#### 2.3.1 新目录结构

```
项目/
├── vela.json              # 项目配置（已有）
├── .vela/                 # Vela 项目元数据（已有）
│   ├── skills/            # 项目级自定义 Skill（已有）
│   └── agents/            # 项目级 Agent 配置（新增）
├── 设定/                  # 世界观/角色/势力（已有，增强）
├── 大纲/                  # 大纲/卷纲/细纲（已有，增强）
├── 正文/                  # 章节正文（已有）
├── 对标/                  # 对标书结构化子目录（新增）
│   └── {书名}/           # 角色/剧情/设定/文风/拆文报告
├── 拆文库/               # 拆文输出目录（新增）
│   └── {书名}/           # 结构化拆解产物
├── 追踪/                 # 连续性管理（新增）
│   ├── 上下文.md          # 写作上下文（compact恢复用）
│   ├── 伏笔.md            # 伏笔埋设/回收状态表
│   ├── 时间线.md          # 故事内时间线
│   └── 角色状态.md        # 角色当前状态快照
└── 参考资料/             # 研究资料（新增）
```

#### 2.3.2 与数据库的关系

- **数据库层（SQLite）**：角色卡、蓝图/细纲元数据、草稿版本 → 不变
- **文件系统层（Markdown）**：对标/拆文/追踪/参考资料 → 新增
- **设定/大纲/正文**：双写（数据库 + 文件系统导出视图）

### 2.4 去 AI 味引擎（P1）

#### 2.4.1 检测流程

| Phase | 内容 | Gate |
|-------|------|------|
| Phase 1 | AI 味扫描 | 7 Gate（禁用词/句式套路/心理告知/节奏均匀/对话腔调/结尾升华/解释腔） |
| Phase 2 | 诊断分级 | 轻度/中度/重度判定 + 处理策略 |
| Phase 3 | 去 AI 改写 | 三遍法：去泛化→去书面化→回自然感 |

#### 2.4.2 UI 集成

- 编辑器中选中文本 → 右键菜单 →「去 AI 味」
- AI 面板 → deai-filter Skill
- 结果显示为 Diff 视图（原文 vs 去 AI 后）

## 3. 非功能需求

| 需求 | 说明 |
|------|------|
| 向前兼容 | v0.1.0 创建的项目可在 v0.2.0 正常打开 |
| 性能 | 28 个 Skill 加载不显著增加启动时间（< 200ms） |
| 内存 | Agent 协作不导致主进程内存泄漏 |
| 离线可用 | 内置 Skill 和 Agent 提示词本地存储，断网可用 |
| 主题一致 | 所有新 UI 遵循 JetBrains Dark/Light 主题规范 |

## 4. 约束条件

| 约束 | 说明 |
|------|------|
| 分支 | 必须 dev 分支，不碰 master |
| 架构 | 不改变 Electron + React + Zustand + SQLite 骨架 |
| 规范 | 遵循 rule.md（中文注释、文件命名、CSS 变量） |
| 数据库 | 不破坏现有 SQLite schema，仅追加表 |
| 语言 | 用户可见文本全部中文 |
