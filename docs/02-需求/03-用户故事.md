# Vela v0.2.0 用户故事

## 角色定义

| 角色 | 简称 | 描述 |
|------|------|------|
| 网文作者 | 作者 | 长篇连载写手，日常日更 3000-6000 字 |
| 短篇作者 | 短篇 | 知乎盐言/番茄短篇写手，每篇 8000-30000 字 |

## 核心用户故事（P0）

### US-001：作为作者，我希望能用 AI 帮我完成从选题到正文的全流程

**场景**：我有了一个创作念头，但不知道怎么展开。

**操作**：
1. 新建项目 → project-init Skill 引导初始化
2. novel-outline Skill：确认选题→核心设定→大纲搭建
3. novel-draft Skill：逐章生成正文
4. deai-filter Skill：去 AI 味精修

**验收**：一个完整的小说项目从立项到第一章正文，不超过 30 分钟。

### US-002：作为作者，我希望多个 AI Agent 帮我各司其职

**场景**：我不需要一个万能 AI，我需要架构师帮我搭结构、写手帮我出正文、检查器帮我找矛盾。

**操作**：
1. AI 面板切换 Agent 为「架构师」→ 讨论世界观
2. 切换为「叙事写手」→ 生成章节正文
3. 切换为「一致性检查器」→ 扫描全文章节找矛盾

**验收**：Agent 切换流畅，输出符合其专业角色。

### US-003：作为作者，我希望看到所有可用 AI Skill 并按需调用

**场景**：我不确定 AI 能帮我做什么，想浏览一下功能列表。

**操作**：
1. 点击侧边栏「Skills」Tab
2. 看到按分类排列的 Skill 列表
3. 点击「去AI味」→ AI 面板自动加载该 Skill
4. 也可以输入 `/去AI味` 直接调用

**验收**：Skill 面板完整展示 28 个 Skill，点选即可用。

### US-004：作为作者，我的小说项目应该有结构化的设定和大纲

**场景**：写了几十章后我发现角色性格前后矛盾、伏笔忘了回收。

**操作**：
1. 侧边栏文件树 → 设定/角色/ → 每个角色独立文件
2. 侧边栏文件树 → 追踪/伏笔.md → 查看伏笔状态表
3. consistency-check Skill 自动扫描设定矛盾

**验收**：项目结构清晰，追踪文件自动更新。

### US-005：作为作者，我希望 AI 帮我检测并去除 AI 写作痕迹

**场景**：AI 生成的正文有明显的 AI 味——过于工整、面面俱到、禁用词频出。

**操作**：
1. 编辑器中选中正文
2. 右键菜单 →「去 AI 味」
3. 查看 Diff 视图对比原文和去 AI 后文本
4. 确认后覆盖原文

**验收**：去 AI 后的文字自然、有口语感、保留原有剧情。

### US-006：作为作者，我需要多视角的审稿

**场景**：写完一章后我想知道写得怎么样。

**操作**：
1. 调用 multi-review Skill
2. 系统触发 4 个维度审查（结构/角色/文字/设定）
3. 生成审稿报告，按严重程度分级标记问题
4. 根据审稿建议逐项修复

**验收**：审稿报告覆盖 S1-S4 四级问题，每项有修改建议。

### US-007：作为作者，我要模拟读者阅读体验

**场景**：我不知道读者读到关键转折处会是什么反应。

**操作**：
1. 调用 reader-sim Skill
2. 选择读者画像（目标平台读者、挑剔读者、路人读者）
3. AI 模拟阅读过程，逐段标注感受
4. 输出情绪曲线和体验报告

**验收**：读者模拟报告有具体感受标注（兴奋/无聊/困惑/满足）。

### US-008：作为作者，我要和我的角色对话

**场景**：我设计的反派总感觉不对，想直接和他对话来发现他的声音。

**操作**：
1. 调用 character-sim Skill
2. 选择目标角色
3. 以作者身份和角色对话
4. 发现角色的语言风格、动机逻辑、隐藏特质

**验收**：角色对话自然，符合角色设定的性格和历史。

### US-009：作为学者，我要拆解爆款小说学习写作套路

**场景**：我想模仿《盘龙》的节奏感和爽点设计。

**操作**：
1. 调用 novel-analyze Skill
2. 提供对标书原文（或选择已导入的对标书）
3. AI 拆解：黄金三章分析、爽点密度、节奏模式、情绪模块
4. 输出结构化拆文报告存入拆文库/

**验收**：拆文报告包含五维评分、可借鉴套路、情绪模块。

## 进阶用户故事（P1）

### US-010：作为新手，我希望能有扫榜功能帮我选方向

**场景**：我想写网文但不知道该写什么题材能火。

**操作**：
1. 调用 market-scan Skill
2. 选择平台（起点/番茄/晋江）
3. AI 分析市场趋势+推荐选题+差异化建议

**验收**：输出选题决策报告，包含可行性排序。

### US-011：作为作者，我要从现有散文创建我的写作风格文件

**场景**：我有 5 章自己写的内容，希望 AI 后续生成的内容匹配我的风格。

**操作**：
1. 调用 style-creator Skill
2. 提供散文样本
3. AI 分析句长/标点/词汇/节奏模式
4. 生成风格参考文件用于后续写作

**验收**：后续 AI 生成内容句式和语气贴近提供的样本风格。

### US-012：作为作者，我希望 AI 帮我找 LLM 默认词/句式

**场景**：AI 生成的文本里总有「命运的齿轮」「心猛地一沉」这种套话。

**操作**：
1. 调用 llm-discipline Skill
2. 自动扫描正文中 LLM 高频默认词
3. 逐一标记+给出替换建议
4. 可批量替换

**验收**：扫描覆盖 50+ LLM 高频默认词和 15+ 默认句式。

## 扩展用户故事（P2）

### US-013：作为作者，我希望研究辅助帮我查资料

**场景**：写历史小说需要查明朝官制。

**操作**：
1. 调用 research-assist Skill
2. 输入研究主题
3. AI 多源搜索+交叉验证+生成结构化研究笔记
4. 存入参考资料/

**验收**：研究笔记有引用来源标注。

### US-014：作为作者，我要 AI 帮我生成标题 A/B 变体

**场景**：章节写好了但想不到好的章节标题。

**操作**：
1. 调用 headline-gen Skill
2. AI 生成 5-10 个标题变体
3. 附带情感影响力评分
4. 选择最佳标题

**验收**：标题变体不重复且有差异化策略。

## P0 MVP 范围

P0 必须交付的功能 = v0.2.0 的核心：
1. 多 Agent 协作（5 核心 Agent）
2. 全流程写作工作流（novel-outline + novel-draft）
3. Skills 面板 + 11 核心 Skill
4. 项目文件结构升级（对标/拆文库/追踪）
5. 去 AI 味引擎
6. 多视角审稿
7. 角色对话模拟 + 读者模拟
8. 拆文分析
9. UI Agent 选择器 + Skill 面板
